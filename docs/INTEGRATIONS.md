# Integrations status

No external integrations are active. Planned boundaries include FHIR/HL7, DICOM/PACS, analyzers, payment providers, accounting, and notification delivery. Each integration requires versioned contracts, server-side authentication, validation, authorization, idempotency, retries, audit, and explicit configuration. Do not represent an unconfigured integration as successful or claim FHIR conformance without mapping and validation.
